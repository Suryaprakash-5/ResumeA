# 📄 ResumeA - Personal Resume Website

## 🚀 Overview

ResumeA is a simple and responsive **personal resume website** built using HTML, CSS, and JavaScript.
It showcases personal details, skills, and a downloadable resume in a clean and user-friendly interface.

This project is designed to help individuals present their profile professionally online.

---

## 🌟 Features

* 📌 Clean and responsive UI
* 📄 Resume preview and download option
* 🖼️ Image-based profile design
* ⚡ Fast and lightweight website
* 🎯 Beginner-friendly structure

---

## 🛠️ Tech Stack

* HTML5
* CSS3
* JavaScript

---

## 📂 Project Structure

```
ResumeA/
│── index.html        # Main webpage
│── home.css          # Styling
│── home.js           # JavaScript functionality
│── images/           # Images and assets
│── resume.pdf        # Downloadable resume
```

---

## 💻 How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/Suryaprakash-5/ResumeA.git
   ```
2. Open the folder
3. Double-click `index.html`
   OR open it in any browser
